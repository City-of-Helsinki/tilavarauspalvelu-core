# T3.2 Move "can apply free of charge" to base components

Label: BE
Blocked by: T2.2

## Background

`ReservationUnit.can_apply_free_of_charge` controls if a reserver can apply for a free reservation.
Some customers need to schedule a change to this. On base components it can be scheduled, and it can differ by price option.

## Scope

- The reserver can apply for a discount if any base component that matches the reservation has `can_apply_for_discount`.
  A reservation over the date of a change matches two base components. "Any" means the reserver keeps the right to apply.
- Reservation create and update use this rule instead of the reservation unit field.
- Remove `can_apply_free_of_charge` from the reservation unit API. Keep the column until the cleanup (T10.1).

## Acceptance criteria

- A scheduled change to `can_apply_for_discount` takes effect from its date.
