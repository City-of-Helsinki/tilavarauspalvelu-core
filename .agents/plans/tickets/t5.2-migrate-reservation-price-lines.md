# T5.2 Migrate existing reservations to price lines

Label: BE
Blocked by: T5.1, T2.7

## Background

Existing reservations have only `price`, `non_subsidised_price`, `unit_price` and `tax_percentage_value`.
All reservations need price lines, so that the code has one way to read prices.

## Scope

- Make one price line for each existing reservation from its price fields.
- If `price` is lower than `non_subsidised_price`, set `override_amount = price`.
- There are about 600,000 reservations. Use batches.

## Acceptance criteria

- Every reservation has price lines whose sum is its price.
