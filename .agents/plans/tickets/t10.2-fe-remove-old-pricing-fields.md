# T10.2 Remove the old pricing fields from the frontend

Label: FE
Blocked by: T3.4, T4.5, T5.6

## Background

After the redesign, the backend removes the old pricing fields (T10.1). The frontend must stop using them first.

## Scope

- Remove `pricings`, `taxPercentage`, `taxPercentageValue`, `unitPrice` and `canApplyFreeOfCharge`
  from all staff and customer queries and fragments.

## Acceptance criteria

- No frontend query uses the removed fields, and the generated types build.
