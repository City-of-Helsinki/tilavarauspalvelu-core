# T1.1 Add TaxLevel and TaxLevelRate models

Label: BE
Blocked by: none

## Background

Staff now select a VAT percentage for each reservation unit pricing. When the VAT rate changes by law,
every reservation unit needs a new pricing. A tax level is a named VAT class, for example "Sports" or "General".
Its rate can change over time without touching the pricings.

## Scope

- Model `TaxLevel`: `name` (translated).
- Model `TaxLevelRate`: `tax_level` → TaxLevel, `begins: date`, `percentage: decimal`, `vat_code: str`.
  Unique `(tax_level, begins)`.
- The rate of a tax level on a date is the rate with the latest `begins` that is on or before that date.
- Django admin for both models. Tax levels and rates are managed only in the Django admin.
- Data migration: make one TaxLevel for each enabled TaxPercentage value in use, named by the percentage,
  with one TaxLevelRate from the earliest date in use. The VAT code is filled in T1.3.

## Acceptance criteria

- An admin can add a tax level and schedule a new rate for it.
- A helper returns the rate and the VAT code of a tax level for a given date.
- Every TaxPercentage in use has a matching tax level after the migration.
