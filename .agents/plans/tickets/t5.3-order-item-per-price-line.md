# T5.3 Send one web shop order item per price line

Label: BE
Blocked by: T5.1

## Background

A web shop order now has one item for the whole reservation. Price lines can have different VAT rates and accountings,
and each web shop order item has its own accounting copy.

## Scope

- Make one order item for each price line with a positive final amount.
- Each item has the line's VAT percentage and amount.
- Refunds work per order item.

## Acceptance criteria

- A reservation with two lines makes an order with two items, and the payment and refund work in the test web shop.
