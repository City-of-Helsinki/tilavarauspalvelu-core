# T6.1 Price options with unit group ownership

Label: BE
Blocked by: T2.1, T9.1

## Background

A price option is a label that the reserver selects, for example "Adults" or "Event A, juniors".
One unit group owns each option, so two organizations can each have an "Adults" option with a different meaning.
Only shared pricing groups can use options.

## Scope

- GraphQL mutations to create and edit price options.
- A user can create and edit an option if they have a role on its unit group.
- The options are shown in name order.
- Turn on the `price_option` field of price components in the validator.

## Acceptance criteria

- Staff can manage the options of their own unit group, and not those of others.
