# T1.7 Name the migrated tax levels

Label: OPS
Blocked by: T1.1

## Background

The migration names each tax level by its percentage, for example "13.5 %". Staff select tax levels by name,
so the names must describe the VAT class, for example "Sports" or "General".

## Scope

- Agree on the tax level names with the product owner.
- Rename the tax levels in the Django admin in each environment.

## Acceptance criteria

- No tax level in production is named only by a percentage.
