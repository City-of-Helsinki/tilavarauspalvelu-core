# T4.1 Price query for reservers

Label: BE
Blocked by: T2.5

## Background

The customer app calculates prices itself from `highestPrice`, `lowestPrice` and `priceUnit`.
With price options, conditions, surcharges and discounts, only the backend can calculate the price.

## Scope

- A GraphQL query: reservation unit, price option (optional), begin and end.
- It returns the price lines that a reservation would get (amount, VAT, description), the total,
  if the reserver can apply for a discount, the payment type, and the material price descriptions.
- It uses the same calculation as reservation create.

## Acceptance criteria

- The query returns the same price as a reservation made with the same input.
