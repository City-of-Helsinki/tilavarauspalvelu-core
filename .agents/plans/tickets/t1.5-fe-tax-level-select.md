# T1.5 Tax level select in the reservation unit pricing form

Label: FE
Blocked by: T1.2

## Background

Staff now select a VAT percentage for each pricing. The list also shows old percentages that are no longer used.
The backend now uses tax levels, for example "Sports" or "General".

## Scope

- Replace the tax percentage select with a tax level select.
- Remove the "activated on begins" checkbox.
- The net price fields use the current rate of the selected tax level.

## Acceptance criteria

- Staff can select a tax level and save the pricing.
- Only tax levels are shown, not percentages.
