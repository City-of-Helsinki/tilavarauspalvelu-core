# T7.3 Confirm several products per reservation unit with the web shop team

Label: OPS
Blocked by: none

## Background

Varaamo will create several web shop products for one reservation unit, one per accounting and tax level.
The `namespaceEntityId` of the new products is a string like `"123:4:5"`, not a number.
The web shop code (`ProductMappingController`, `findByNamespaceEntityId`) suggests that this works, but nobody has tested it.

## Scope

- Ask the web shop team if several products per entity and string entity IDs are supported.
- Ask if `activeFrom` and `nextEntity` on product accounting are supported and in use by other services.

## Acceptance criteria

- A written answer from the web shop team, linked in T7.1 and T7.2.
