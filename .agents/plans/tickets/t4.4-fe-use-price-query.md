# T4.4 Use backend prices in the customer app

Label: FE
Blocked by: T4.1, T4.2, T4.3

## Background

The customer app calculates prices itself (`getPriceString` and related code in `apps/customer/src/modules/reservationUnit.ts`).
The backend now gives the price query (T4.1) and the price summary (T4.2). This applies to all reservation units.

## Scope

- Use the price summary on search cards, lists and the reservation unit page.
- Use the price query in the reservation flow and the reservation edit flow.
- Show the "apply for free of charge" fields if the price query allows it.
- Show the material price descriptions from the price query.

## Acceptance criteria

- Every customer view that shows a price uses the backend.
