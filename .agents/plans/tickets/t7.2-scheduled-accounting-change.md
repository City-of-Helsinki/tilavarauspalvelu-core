# T7.2 Scheduled accounting change in the web shop when a VAT rate changes

Label: BE
Blocked by: T7.1

## Background

The web shop accounting of a product has a VAT code. When a tax level gets a new rate, the VAT code changes on a date.
The web shop accounting has `activeFrom` and `nextEntity` fields for a scheduled change. Varaamo does not use them yet.

## Scope

- When a new `TaxLevelRate` is added, a task sends `nextEntity` with `activeFrom` set to the rate's `begins` date
  for every product that uses that tax level.
- Log products where the update fails.

## Acceptance criteria

- After a scheduled rate change, the web shop uses the new VAT code from the change date, with no manual step.
