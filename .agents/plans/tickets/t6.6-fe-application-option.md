# T6.6 Price option selection in the application form

Label: FE
Blocked by: T6.2, T6.4

## Background

The reserver selects a price option, for example "Adults", and the price depends on it. The backend stores the option (T6.2).

## Scope

- Show the options of the round for each application section.
- Send the selected option with the application section.

## Acceptance criteria

- The form follows the design from T6.4.
