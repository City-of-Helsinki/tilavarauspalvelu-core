# T9.2 Price preview with unsaved changes

Label: BE
Blocked by: T2.4, T4.1

## Background

The validator cannot find every mistake in a pricing group, for example the same surcharge added twice.
Staff need to see the price that a reservation would get before they save.

## Scope

- A GraphQL query: pricing group, a batch of unsaved changes (the same shape as the batch API in T2.4),
  a price option, a date and a time range.
- It merges the batch with the saved components and returns the price lines that a reservation would get.
- It returns coverage errors too, if the merged group is not valid.

## Acceptance criteria

- The preview with an empty batch gives the same price as the price query (T4.1).
