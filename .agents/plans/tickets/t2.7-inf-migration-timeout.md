# T2.7 Check that the deploy fits the data migrations

Label: INF
Blocked by: none

## Background

The pricing redesign has data migrations that touch all reservation units and, in T5.2, about 600,000 reservations.
A deploy that takes too long can fail in the migration step.

## Scope

- Measure the run time of the migrations on a copy of the production database.
- Check the timeout of the migration step in the OpenShift deploy.
- If needed, raise the timeout, or plan the deploy outside office hours.

## Acceptance criteria

- The measured run time and the timeout are written in the ticket, and the deploy plan is agreed.
