# T9.4 Pricing group editor

Label: FE
Blocked by: T2.4, T9.1, T9.3

## Background

Shared pricing groups are edited in a new staff view. The backend saves changes to a group as one batch (T2.4).

## Scope

- List the shared pricing groups that the user can edit.
- Create and rename groups.
- Edit the components of a group and save them as one batch.
- Show errors for the whole group, also on components the user did not change.

## Acceptance criteria

- The editor follows the design from T9.3.
