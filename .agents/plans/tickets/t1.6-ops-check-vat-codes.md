# T1.6 Check the VAT codes per VAT rate with finance

Label: OPS
Blocked by: none

## Background

Payment accountings have an SAP VAT code, for example "44". Varaamo will store one VAT code per VAT rate,
not per accounting. We do not know how SAP maps codes to rates.

## Scope

- List the VAT codes in use in production per VAT percentage.
- Confirm with the finance team which SAP VAT code belongs to each VAT rate.
- Ask if SAP requires that the product VAT code matches the VAT percentage of the order item.

## Acceptance criteria

- A confirmed table of VAT rate → SAP VAT code exists before the T1.3 migration runs in production.
