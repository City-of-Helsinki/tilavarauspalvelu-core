# T5.4 Handler override per price line

Label: BE
Blocked by: T5.1

## Background

A handler can make a reservation free, and the PO wants to allow price corrections too.
An override per price line lets the handler make one part free, or correct a wrong price.

## Scope

- The approve mutation takes an `overrideAmount` per price line.
- If it is set, it is the final amount of the line. It is applied after adjustments.
- Keep the current "free of charge" behavior: it sets every override to 0.

## Acceptance criteria

- A handler can set one line to 0 and keep another line paid.
- The web shop order uses the overridden amounts.
